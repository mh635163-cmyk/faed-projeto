# faed-projeto

12/11/2026 
Adição do projeto ao github, para melhoria de organização de trabalho

Projeto de FAED pré requisitos: 

Como adicionar o projeto ao Git Extensions

1. Copiar o link do GitHub

Abrir o repositório no GitHub.

Clicar em Code.

Selecionar HTTPS.

Copiar o link.

2. Clonar o projeto

Abrir o Git Extensions.

Clicar em Clone repository.

Colar o link em Repository to clone.

Escolher a pasta onde guardar o projeto em Destination.

Clicar em Clone.

3. Trabalhar no projeto

Depois de clonar, já podes abrir e editar os ficheiros do projeto.

Sempre que quiseres trabalhar:

Pull: receber as alterações dos colegas.

Commit: guardar as tuas alterações.

Push: enviar as tuas alterações para o GitHub.
